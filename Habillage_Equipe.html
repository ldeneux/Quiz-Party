Équipe : Soleil Rouge

Prompt – Avatars

Créer une planche de 12 avatars 1024×1024, style cartoon futuriste, très colorés, fond transparent,
représentant l’équipe Soleil Rouge dans le thème Espace.

Style visuel : illustration propre, moderne, lisible, contours nets, glow léger.
Palette : bleu cosmos, violet nébuleuse, turquoise, rose galactique, or stellaire.
Contraintes : aucun texte, aucun chiffre, fond transparent obligatoire, format carré.
Organisation : grille propre 4×3 ou 3×4, avatars centrés, sans décor intrusif.

Prompt – Fond d’écran paysage

Créer un fond d’écran individuel, style jeu vidéo réaliste stylisé, représentant l’équipe Soleil Rouge
dans l’univers Espace. Générer une seule image au format paysage 1920×1080.

Contraintes de composition :
- Centre de l’image dégagé, clair, sans éléments visuels forts.
- Haut de l’image sobre, légèrement lumineux, sans décor intrusif.
- Décor autour, jamais dans la zone centrale.
- Style jeu vidéo, lumière volumétrique, ambiance cosmique.
- Aucun texte, aucun symbole typographique.

Palette : bleu cosmos, violet nébuleuse, turquoise, rose galactique, or stellaire.
Optimisation upscale HD : textures nettes, détails propres, contours précis, sans bruit numérique.

Prompt – Icônes de jeu et navigation

Créer une planche d’icônes 4096×4096 px sur le thème de l’Espace.
La planche doit contenir 12 icônes, organisées en grille, avec un style homogène, clair et lisible.

1) Icônes “Modes de jeu” :
- Classique : planète stylisée avec orbite lumineuse
- Défi : météorite en flammes bleues
- Survie : capsule de secours ou combinaison spatiale
- Collaboratif : deux astronautes se tenant la main
- Trivial Pursuit : disque galactique segmenté façon camembert

2) Icônes “Boutons d’action” :
- Démarrer : fusée qui décolle
- Nouvelle partie : portail spatial qui s’ouvre
- Question suivante : flèche intégrée à un satellite
- Quitter : vaisseau s’éloignant dans l’espace
- Score : coffre futuriste rempli de cristaux stellaires
- Progression : barre d’énergie ou orbite évolutive
- Paramètres : roue crantée en forme de module spatial

Style visuel :
- Univers spatial, nébuleuses, étoiles, planètes.
- Icônes vectorielles ou semi‑réalistes, très lisibles même en petit format.
- Couleurs bleu cosmos, violet nébuleuse, touches dorées.
- Bordures inspirées des motifs technologiques futuristes.
- Ombres douces, relief léger.

Organisation de la planche :
- Grille propre 4×3 ou 3×4.
- Icônes centrées dans leurs cases.
- Aucun texte.
- Fond neutre (noir profond ou bleu nuit).

Format final :
- Planche 4096×4096 px.
- Icônes bien séparées, prêtes à être exportées individuellement.

Prompt – Fond d’écran principal

Créer un fond d’écran immersif sur le thème de l’Espace.

La composition doit être parfaitement structurée pour un jeu de quiz :
- Espace central large et dégagé, très lisible, prévu pour afficher des questions.
- Deux grandes zones latérales, à gauche et à droite, sous forme de panneaux holographiques,
  pour afficher les scores et les équipes.

Décor général :
- Vaste vue spatiale : planètes, nébuleuses, étoiles, anneaux, vaisseaux en arrière‑plan.
- Lumière venant du haut ou d’un soleil stylisé, ambiance cosmique.
- Sol ou base futuriste discrète, avec quelques éléments technologiques.

Style visuel :
- Très détaillé, réaliste stylisé, cinématique.
- Atmosphère majestueuse, inspirée des grandes scènes de science‑fiction.
- Les panneaux latéraux doivent être visibles mais ne pas voler l’attention du centre.
- Le centre doit rester propre, neutre, sans éléments intrusifs.

Format :
- Large panorama horizontal.
- Idéal pour interface de jeu.
- Ne pas ajouter de texte.
